# Workshop Design Template

Use this repository as a starting point for planning and delivering workshops.

## Structure

- `workshop-design/`: planning templates
- `.github/ISSUE_TEMPLATE/`: issue forms
- `.github/workflows/`: automated checks
- `docs/`: GitHub Pages content

## Getting started

1. Click **Use this template** on GitHub.
2. Create a **Workshop design plan** issue from the issue form.
3. Fill in the files under `workshop-design/`.
4. Enable GitHub Pages from the repository settings using the `/docs` folder.
