# Workshop Design Template

This repository now includes:

- the original markdown-based planning workflow (`workshop-design/`, `docs/`, `examples/`)
- a static GitHub Pages wizard app (`workshop-planner/`) for interactive workshop design

## Interactive web app

The `workshop-planner/` app is a React + Vite single-page wizard for bioinformatics workshop design.

### Run locally

```bash
cd workshop-planner
npm install
npm run dev
```

### Test validation logic

```bash
cd workshop-planner
npm test
```

### Build for GitHub Pages

```bash
cd workshop-planner
npm run build
```

See `/home/runner/work/workshop-design-template/workshop-design-template/workshop-planner/README.md` for architecture and deployment details.

## Existing template resources

- `workshop-design/`: planning templates
- `docs/`: static pathway documentation
- `examples/`: complete worked example
