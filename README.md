# Workshop Design Template

Use this repository as a starting point for planning and delivering workshops.

The template now follows a guided BioCommons Workshop Designer pathway that starts from learner needs and then builds scope, outcomes, practice, and delivery readiness.

## Structure

- `workshop-design/`: planning templates
- `.github/ISSUE_TEMPLATE/`: issue forms
- `.github/workflows/`: automated checks
- `docs/`: GitHub Pages content

## Getting started

1. Click **Use this template** on GitHub.
2. Create a **Workshop design plan** issue from the issue form.
3. Follow the 12-step flow in `docs/index.md`.
4. Fill in the planning files under `workshop-design/`.
5. Open a **Content review** issue before delivery.
4. Enable GitHub Pages from the repository settings using the `/docs` folder.

## 12-step design flow

1. Start with the learner problem
2. Define audience and prerequisites
3. Brain dump candidate content
4. Triage essentials and parking lot items
5. Write measurable learning outcomes
6. Run a reality check against available time
7. Build teaching and assessment for each outcome
8. Build the runsheet
9. Complete accessibility checks
10. Complete delivery checklist
11. Publish workshop materials
12. Capture post-delivery reflection
