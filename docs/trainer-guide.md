# Trainer Guide

Use this guide to prepare delivery, timing, and facilitation.

## Design principles

- Start from participant scientific problems, not content inventory.
- Limit scope to what can be practiced in available time.
- Prefer measurable learning outcomes.
- Balance explanation with guided practice.

## Coaching prompts

- What can participants do by the end that they cannot do now?
- Which topics are essential for this delivery?
- Which items should move to parking lot or follow-up resources?

## Delivery preparation

Before delivery, complete:
- Runsheet
- Accessibility check
- Delivery checklist
