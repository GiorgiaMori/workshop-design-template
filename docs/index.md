# Workshop Materials

Welcome to the BioCommons Workshop Designer pathway.

Use this guide to design workshops that are realistic, learner-focused, and delivery-ready.

## Guided pathway

1. Start with learner problem and scope
2. Define audience and prerequisites
3. Brain dump candidate content
4. Triage essentials and parking lot
5. Write measurable learning outcomes
6. Reality check against time
7. Build outcomes into teaching and assessment
8. Build runsheet and timing
9. Complete accessibility checks
10. Complete delivery checklist
11. Publish materials
12. Reflect after delivery
