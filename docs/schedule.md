# Schedule

Draft the session timeline and breaks.

## Scheduling guidance

- Include setup and transition time.
- Include at least one break every 90 minutes.
- Keep a buffer of 10-20% for troubleshooting.

## Minimum structure

- Opening context
- Demo + exercise cycles
- Debriefs
- Closing and next steps

Use `workshop-design/05-runsheet.md` and `workshop-design/06-reality-check.md` to validate feasibility.
