# Scope

Start with the learner's scientific problem before naming the workshop topic.

## Learner problem statement

Complete this sentence:

"Participants are trying to solve this real-world problem:"

Examples:
- I have Nanopore reads and want to assemble a genome.
- I need to analyse single-cell RNA-seq data.
- I want to run a Nextflow pipeline on HPC.

## Workshop topic

Now name the workshop topic that supports the problem.

## In scope

List what this workshop must cover to solve the learner problem.

## Out of scope

List what this workshop will not cover live.

## Constraints

- Delivery length (for example: 3h, 6h, full day)
- Delivery mode (online, in-person, hybrid)
- Platform constraints (HPC access, software install policy, account setup)
- Team constraints (number of trainers/facilitators)
