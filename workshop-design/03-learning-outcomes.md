# Learning Outcomes

Write measurable outcomes tied to participant actions.

Use this sentence stem:

"After this workshop, participants will be able to..."

Avoid vague verbs such as:
- understand
- know
- appreciate

Prefer measurable verbs such as:
- run
- identify
- interpret
- compare
- troubleshoot
- evaluate

Recommended maximum:
- Half-day workshop: 3 outcomes

## Outcome quality check

For each outcome, confirm:
- Can participants demonstrate this during the workshop?
- Is there at least one matching activity?
- Can trainers observe evidence of achievement?
