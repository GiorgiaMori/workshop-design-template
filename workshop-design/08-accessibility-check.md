Use questions to identify participant barriers and required accommodations.

## Access questions

Will participants need to:
- Distinguish colours in figures or interfaces?
- Watch videos or listen to audio?
- Install software locally?
- Use a terminal?
- Work in breakout rooms?

For each "yes", write a mitigation.
