# Facilitation Plan (Example)

## Role assignments

### Trainer
- Deliver mini-lectures and demos
- Own pacing decisions
- Lead debriefs

### Facilitators
- Support exercise troubleshooting in chat and breakout help room
- Track recurring blockers
- Escalate systemic issues to trainer

### Host
- Open/close session, monitor recording policy, manage breakouts
- Post key links and announcements

## Checkpoints

- Mid-session pulse check: confidence poll after exercise 1
- Debrief prompts: one technical, one interpretation question per exercise
- Escalation: if 20%+ participants blocked, pause and run whole-group recovery
