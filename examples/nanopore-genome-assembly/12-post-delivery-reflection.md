# Post-Delivery Reflection (Example)

## What worked

- Participants completed all three exercises with facilitator support.
- Outcome framing improved confidence during interpretation tasks.
- Pre-provisioned environment removed setup delays.

## What did not work

- BUSCO explanation took longer than planned.
- Some participants needed extra terminal navigation support.

## Evidence from participants

- Feedback highlights: practical exercises were highly valued.
- Common blockers: path errors and file naming mistakes.
- Outcomes achieved/not achieved: LO1-LO3 strong; LO4 achieved with facilitator prompting.

## Actions for next iteration

- Keep: Flye and QUAST core flow.
- Change: simplify BUSCO segment and add a quick glossary.
- Remove: one optional troubleshooting branch from exercise 3.
- Add to parking lot/resources: advanced polishing and hybrid assembly.
