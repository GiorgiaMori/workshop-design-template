# Exercises (Example)

## Exercise 1: Assemble reads with Flye

- Purpose: produce initial assembly from provided long reads
- Linked outcomes: LO1
- Duration: 40m
- Required setup/data: sample FASTQ and prepared environment
- Success criteria: assembly output files generated successfully
- Common mistakes and hints: incorrect input path; memory flag mismatch

## Exercise 2: Assess assembly quality

- Purpose: run QUAST and BUSCO, interpret report fields
- Linked outcomes: LO2, LO3
- Duration: 40m
- Required setup/data: assembly FASTA from exercise 1
- Success criteria: participant summarizes quality decision in worksheet
- Common mistakes and hints: wrong BUSCO lineage; misreading fragmented vs complete

## Exercise 3: Troubleshoot a failed run

- Purpose: diagnose and correct a seeded assembly failure
- Linked outcomes: LO4
- Duration: 35m
- Required setup/data: failing logs and command history
- Success criteria: participant identifies root cause and reruns corrected command
- Common mistakes and hints: focusing on final error line only
