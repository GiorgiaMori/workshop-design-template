# Learning Outcomes (Example)

After this workshop, participants will be able to:

1. Run a long-read bacterial genome assembly using a provided Flye command template.
2. Evaluate assembly quality using QUAST and BUSCO outputs.
3. Interpret assembly metrics (for example N50, number of contigs, completeness) to determine whether an assembly is acceptable for downstream analysis.
4. Troubleshoot common assembly failures using logs and simple corrective actions.

## Outcome quality check

- Demonstrable in workshop: Yes (commands and report interpretation)
- Matching activities: Yes (three hands-on exercises)
- Observable evidence: Yes (submission of short interpretation answers)
