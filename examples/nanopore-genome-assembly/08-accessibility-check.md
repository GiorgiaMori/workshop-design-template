# Accessibility Check (Example)

## Access questions

Will participants need to:
- Distinguish colours? Yes -> use colour-safe palettes and shape markers
- Watch videos/audio? No mandatory video content
- Install software? No -> pre-configured environment provided
- Use a terminal? Yes -> provide command templates and paced walkthrough
- Work in breakout rooms? Optional, with clear alternatives

## Delivery accommodations

- Captioning/transcripts: live captions enabled
- Font size and contrast: slides use high-contrast theme and minimum 24pt body text
- Keyboard-only navigation: all required resources keyboard accessible
- Alternative formats: all worksheets available as markdown and PDF
- Low-bandwidth fallback: static screenshots and downloadable command logs
