# Audience (Example)

## Participant profile

- Mixed audience (wet-lab researchers and early-career bioinformaticians)

## Experience level

- Some experience

## Current capabilities

Participants can:
- Use terminal basics (cd, ls, cat)
- Run simple command-line tools from a provided environment
- Explain FASTQ/FASTA formats at a high level

## Prerequisites

- Familiarity with sequencing experiment context
- Ability to use SSH or browser terminal provided by host
- Completed setup check before session

## Assumptions to avoid

- Do not assume experience with HPC schedulers
- Do not assume command-line troubleshooting confidence
- Do not assume understanding of assembly graph theory
