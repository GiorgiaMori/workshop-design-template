# Demo Plan (Example)

## Demo list

### Demo 1: Launch Flye with provided command template
- Goal: reduce command anxiety and show expected runtime/log behavior
- Linked outcomes: LO1
- Live steps: show command, explain key flags, run short test subset
- Expected result: assembly directory structure appears

### Demo 2: Navigate QUAST/BUSCO outputs
- Goal: teach where key quality evidence lives
- Linked outcomes: LO2, LO3
- Live steps: open report sections, compare complete vs weak assembly
- Expected result: participants can locate core metrics quickly

### Demo 3: Troubleshoot from logs
- Goal: model a repeatable troubleshooting process
- Linked outcomes: LO4
- Live steps: read error context, check resources, rerun corrected command
- Expected result: corrected run succeeds

## Risks and fallback

- Risk: environment outage -> fallback to pre-generated outputs and guided interpretation
- Risk: command runtime too slow -> use cached results for debrief
- Risk: participant setup failure -> assign to shared helper room with facilitator
